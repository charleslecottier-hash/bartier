# AEO : être la réponse choisie par Google, ChatGPT, Perplexity et Copilot

Date : 18 novembre 2026. Site : https://bartier-8b.vercel.app (futur bartierandco.com).

## 1. En bref

- Les deux guides officiels disent la même chose : l'AEO, c'est du bon SEO, avec des réponses courtes, autonomes et bien titrées. Google l'écrit noir sur blanc : optimiser pour l'IA, « c'est encore du SEO ».
- Le site couvre maintenant les 20 questions cibles avec un intertitre et une réponse courte. Il en couvrait 10 avant cette passe.
- Rien ne remontera dans les réponses des IA tant que le site n'est pas indexé. C'est l'étape décisive, et elle dépend du domaine.

## 2. Ce que disent les sources

| Source | Ce qui compte | Ce qui ne sert à rien |
|---|---|---|
| Google, guide « Optimizing your website for generative AI features » et page « AI features and your website » | Page indexée et autorisée en extrait ; contenu utile et non banal (expérience de première main) ; titres et sections clairs ; texte lisible sans JavaScript ; données structurées identiques au texte visible ; images et vidéos de qualité ; fiche Google Business Profile à jour | llms.txt (« Google Search ne l'utilise pas ») ; découper le contenu en petits morceaux ; réécrire « pour l'IA » ; balisage spécial ; chercher des mentions artificielles ; créer des pages par variante de requête (sanctionné comme contenu de masse) |

## 3. Ce qui a été fait

| Action | Pourquoi |
|---|---|
| Page **Lexique** : 22 définitions de 2 ou 3 phrases, avec les mots des artisans et des propriétaires (« demande de devis », « demande partagée », « taux de signature »). Le jargon des plateformes (« lead ») n'est cité que dans les définitions | Les questions « c'est quoi… » sont la cible type des moteurs de réponse. On parle comme le client, et la page répond aussi à celui qui tape le jargon |
| Sources officielles citées : CNIL, Code de la consommation, Service-Public, DGCCRF, ministère de la Transition écologique, France Rénov', Annuaire des entreprises | Effet mesuré des citations (étude GEO) et crédibilité. Chaque adresse a été vérifiée |
| Données structurées `DefinedTermSet` pour le lexique, identiques au texte visible | Recommandation de Google : données conformes au texte |
| Intertitres des articles réécrits en questions (« Quand relancer un devis ? », « Comment mesurer l'effet de vos relances ? ») | Microsoft et AirOps : un intertitre proche de la question est plus souvent repris |
| Article sur les demandes partagées retitré en français courant, sans changer son adresse | Le langage des clients, sans casser de lien |
| Intertitres vagues renommés (« En bref » devient « Devis toiture : l'essentiel », « Vos questions » devient « Devis toiture : vos questions ») | Microsoft : pas d'intertitre vague |
| Descriptions des pages métiers alignées sur leur titre ; titre de l'accueil sans tiret long | Microsoft : titre, H1 et description cohérents ; ponctuation simple |
| Deux réponses rendues autonomes (« Pour trouver des chantiers, un artisan a cinq canaux… ») ; une question ajoutée sur le devis obligatoire | Une réponse doit se comprendre sortie de son contexte |
| llms.txt : réponses d'une ligne aux questions principales, lien vers le lexique | Inutile pour Google, utile pour les autres assistants qui lisent ce fichier |
| À la mise en ligne, extraits longs autorisés (`max-snippet:-1, max-image-preview:large`) | Google et Bing choisissent les extraits dans ce que la page autorise |
| Lien vers le lexique dans le pied de page de toutes les pages | Liens internes (Google) |

## 5. Points d'attention

- **Questions repliées.** Microsoft conseille de ne pas cacher les réponses dans des menus dépliants. Ici, les réponses sont déjà dans le code HTML de la page, sans JavaScript : les robots qui lisent le HTML les voient. Elles sont aussi dans les données structurées et dans llms-full.txt. Si vous voulez aller plus loin, on peut afficher ouvertes les deux premières questions de chaque page.
- **Pas de raccourci.** Google et Microsoft disent tous les deux qu'aucune technique ne garantit d'être cité.
- **Pas de pages en série.** Une page par variante de requête est sanctionnée par Google. Le lexique est une seule page.
