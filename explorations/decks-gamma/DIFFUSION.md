# Decks Gamma (particuliers) : diffusion

Huit guides courts pour les propriétaires, publiés pour être lus et cités par les moteurs et les IA.
Chacun renvoie vers la page du site qui traite le sujet.

## Étapes
1. Dans Gamma, pour chaque deck : Partager, accès public (toute personne disposant du lien).
   Si Gamma propose l’indexation par les moteurs de recherche, l’activer.
2. Les PDF sont prêts dans pdf/ (titre, auteur et mots-clés renseignés, liens vers le site cliquables).
   Ils portent le badge « Made with Gamma » du plan gratuit ; un plan payant de Gamma permet de le retirer avant un nouvel export.
3. Publier le PDF, avec le titre, la description et le lien ci-dessous, sur :
   - la page LinkedIn de Bartier & Co (publication de type document) ;
   - Calaméo, Issuu, Scribd (SlideShare passe par Scribd).
4. Un deck par jour plutôt que tout le même jour.

Les liens de ces plateformes sont souvent en nofollow : l’intérêt principal est la mention de la marque
à côté du sujet, dans des pages que les IA lisent, et les visites.
